# Атлас промпт-инъекций

[English](README.md)

Личный офлайн-справочник для работы с промпт-инъекциями. Он держит большой каталог опубликованных техник с их первоисточниками рядом с небольшим набором практических разборов — чтобы новую идею из чьего-то исследования можно было быстро найти и воспроизвести на разрешённом агенте. Интерфейс двуязычный (английский / русский), переключатель в верхней панели; выбор запоминается в браузере.

> [!NOTE]
> Это учебный и red-team справочник. Примеры остаются на уровне механизма и используют нейтральный маркер (`BEACON` / `МАЯК`) вместо вредоносного payload — полные payload находятся в связанных первоисточниках. Запускай что-либо только на системах, на которые у тебя есть разрешение.

## Два раздела

- **Подробные разборы** (`index.html`) — 14 написанных вручную кейсов, прямые и непрямые, в каждом: механизм, лабораторный пример с безопасным маркером, как проверить, признаки удержания/сбоя и что исправлять.
- **Полный каталог** (`catalog.html`) — более 2 000 записей из восьми источников (методы, стратегии, пробы, модули, преобразователи, статьи и работы). В каждой записи — описание, **пример использования**, конкретные шаги **как проверить на агенте** и прямая ссылка на первоисточник. Число записей не равно числу уникальных техник.

## Как открыть

Это статический сайт — без сборки.

- Открой `index.html` в браузере или подними папку (`python -m http.server`) и открой `http://localhost:8000/`.
- По HTTPS устанавливается как PWA и работает офлайн.

## Источники

Promptfoo, Microsoft PyRIT, JailbreakBench, Jailbreak Foundry, 0DIN AI Scanner, ML Sanity, LLM-Hacking и RedDarwin. Каждая запись ссылается на свой источник; полный список — в приложении (раздел «Источники» / каталог). Сторонние материалы принадлежат их авторам.
